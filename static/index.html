Importing Subtitles into DaVinci Resolve Free

DaVinci Resolve Free doesn't have automatic speech-to-text built in, but supports standard .SRT subtitle files. Follow these simple steps:

1

Open Your Project & Go to the Edit Page

In DaVinci Resolve, click on the Edit tab (third icon at the bottom, or press Shift + 4).

2

Import the .SRT File

From the top menu, go to File > Import > Subtitle... and select your downloaded .srt file from Video Tuxedo. Alternatively, drag and drop the .srt file directly into the Media Pool.

3

Place on the Timeline

Drag the imported subtitle clip from the Media Pool onto your timeline. DaVinci will automatically create a dedicated Subtitle Track (ST1). The subtitle blocks will align to your audio timecode.

4

Customize Font, Colors & Background

Select any subtitle block on the timeline and open the Inspector panel (top-right). Under Track Style, you can change the font, size, drop shadow, text color, and background box for all subtitles at once.

Importing Cut Timeline & Subtitles into DaVinci Resolve

Follow these simple steps to import your cut sequence with 100% original camera quality and frame-synced subtitles:

1

Open Your Project & Go to the Edit Page

In DaVinci Resolve, click on the Edit tab (third icon at the bottom, or press Shift + 4).

2

Import the .xml Timeline

From the top menu, go to File > Import > Timeline... and select your downloaded *_cuts.xml file (or *_cuts.fcpxml) from ~/Downloads/.

💡 Crucial Settings in the "Load XML..." Dialog:
• Clean Single Audio Track: All takes are placed onto V1 and a single linked audio track A1 (no redundant second tracks).
• Default 1080 x 1920 Resolution: Vertical smartphone timelines now default directly to Full HD 1080 x 1920 (9:16). In the dialog, uncheck "Use project settings" so DaVinci adopts 1080 x 1920 without black side bars.
• Tip if already imported as horizontal: Right-click the timeline in the Media Pool > Timelines > Timeline Settings... > check "Use Vertical Resolution"!
• Make sure "Automatically import source clips into media pool" is checked.
• Click Ok!
3

Import the Synced .SRT Subtitles

Go to File > Import > Subtitle... and select your downloaded *_cut_subtitles.srt. DaVinci will automatically add track ST1 with each phrase synchronized to the jump cuts!

4

100% Original Camera Master Quality

Your timeline is now fully assembled with non-destructive cuts and matching subtitles, using 100% of your camera's original color depth and bitrate with zero compression loss!
