Importing Subtitles into DaVinci Resolve Free

DaVinci Resolve Free doesn't have automatic speech-to-text built in, but supports standard .SRT subtitle files. Follow these simple steps:

1

Open Your Project & Go to the Edit Page

In DaVinci Resolve, click on the Edit tab (third icon at the bottom, or press Shift + 4).

2

Import the .SRT File

From the top menu, go to File > Import > Subtitle... and select your downloaded .srt file from Video Tuxedo. Alternatively, drag and drop the .srt file directly into the Media Pool.

3

Place on the Timeline

Drag the imported subtitle clip from the Media Pool onto your timeline. DaVinci will automatically create a dedicated Subtitle Track (ST1). The subtitle blocks will align to your audio timecode.

4

Customize Font, Colors & Background

Select any subtitle block on the timeline and open the Inspector panel (top-right). Under Track Style, you can change the font, size, drop shadow, text color, and background box for all subtitles at once.
